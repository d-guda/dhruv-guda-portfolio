## Educational security work

The login lab deliberately retains SQL injection and weak password hashing for isolated, authorized study. Read its [security guidance](coursework/SECURITY.md) before running it. Never enter real credentials or deploy the lab publicly.

Organization-specific assessments are educational models, not verified internal audits or confirmed breach findings. Proposed controls and modeled residual scores are not measured improvements. S.O.F.T. credits Dhruv Guda and Owen Kedroski.
